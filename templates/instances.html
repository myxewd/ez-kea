Add an Endpoint

A local endpoint is a Kea host EZ-KEA can read files on (the daemon's own config). An HTTP endpoint is a daemon exposing its control socket over HTTP/HTTPS: EZ-KEA pulls the running configuration with config-get into a local mirror, every page shows that mirror, and Apply replays the edits made here onto the daemon's current configuration and pushes that with config-test → config-set → config-write. Pulling keeps edits that have not been applied yet; tick "discard my edits" to take the daemon's copy instead.
